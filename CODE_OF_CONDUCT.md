# Code of Conduct

We want Forma Studio to be a welcoming project for everyone.

- Be respectful. Disagree with ideas, not people.
- Assume good faith, and say so when you are not sure what someone meant.
- No harassment, insults, discrimination or personal attacks.
- Keep discussion on topic and constructive.

The maintainer may edit or remove comments, close issues and pull requests, or block people who break these rules. To report a problem, use a private [security advisory](https://github.com/Pyram1nx/Forma-Studio/security/advisories/new) or contact the maintainer through their GitHub profile.
